An entry for the make.fun bounty [Describe Your Ex in One Word](https://make.fun/bounty/u-puan-describe-your-ex-in-one-word-9fc6ebe7).

Running `main.py` (Python 3.13, standard library only, no network) writes
one original one-word verdict (8 characters) to `/output/entry.txt`:

> Recalled

A product-recall verdict on an ex: he was taken back by the manufacturer
like a faulty unit — and the word doubles as "I recall him", which is
the complaint itself. It reads instantly as a verdict on a former
partner, lands through the recall twist rather than a plain insult,
and is not the obvious "Expired" / "Mistake" / "Toxic". One plain word,
no punctuation tricks. It runs identically every time.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
